# 도담 숏츠 인스타그램 캡션 (2026-10-28)

53초 세로 영상 "AI가 짜고, 컴파일러가 지킨다"를 인스타그램 릴스로 올릴 때 쓰는 글이다. 피드에서는 앞의 두 줄만 보이고 나머지는 '더 보기'로 접히므로, 핵심을 첫 두 줄에 넣었다.

## 캡션

```text
제대로 돌아가는 AI 코드, 절반이 공격에 뚫렸습니다.
그래서 언어를 새로 만들기로 했어요. 이름은 도담.

AI가 짠 백엔드 코드에 실제 공격을 돌려 본 2025년 연구(BaxBench)에서, 테스트를 통과한 코드의 약 절반이 뚫렸어요. 모델은 계속 좋아지는데 보안 점수는 제자리예요.

도담은 AI가 짜고, 컴파일러가 지키는 언어입니다.
✔ 검증 안 된 입력을 그대로 쓰는 코드는 컴파일되지 않아요
✔ 이름만 바꾼 복붙 코드는 컴파일 에러, 있던 함수를 쓰라고 알려 줘요
✔ 데이터는 한 번만 정의하면 DB 스키마 · 검증 · 동기화를 컴파일러가 만들어요
✔ 사람은 코드 대신 보안 보고서를 보고, 늘어난 권한만 승인해요

방향은 취향이 아니라 숫자로 정합니다. 먼저 AI가 Python · TypeScript 같은 기존 언어 7개로 짠 코드를 630번 재서, 도담이 넘어야 할 기준을 만듭니다.
2026년 말 비교 기준 → 2027년 6월 첫 컴파일러 → 2029년 1.0

AI가 짠 코드, 어디까지 믿고 배포하시나요? 댓글로 알려 주세요.

#바이브코딩 #AI코딩 #개발자 #프로그래밍 #도담언어
```

## 올릴 때

- **해시태그는 5개만 넣었다.** 인스타그램이 2025년 12월부터 게시물 하나에 해시태그를 5개까지만 받는다는 보도가 많다. 공식 도움말에서 직접 확인하지는 못했지만, 5개면 어느 쪽이든 문제가 없다. `#도담`만 쓰면 아기 성장 · 가게 이름 같은 다른 글과 섞여서 `#도담언어`로 했다.
- **커버**는 14초쯤 '도담' 로고가 뜬 장면으로 고른다. 프로필 격자(3:4)로 잘려도 로고가 다 보이는 것을 확인했다.
- 아직 공개 저장소와 웹사이트가 없어서 링크는 넣지 않았다.

## 확인한 근거

- **약 절반이 뚫렸다**: BaxBench(ICML 2025 논문). 백엔드 과제 392개에 실제 공격을 돌렸고, 모델마다 테스트를 통과한 코드의 약 50%가 공격에 뚫렸다. 가장 잘한 모델(o1)도 정확도가 62%였다. 2026-10-28에 논문 원문으로 다시 확인했다.
- **보안 점수는 제자리**: Veracode 2025~2026 보고서. AI가 짠 코드의 보안 통과율은 45~56%였고, 모델이 커져도 나아지지 않았다. 업체 보고서라 논문만큼 검증되지는 않았다.
- **630번**: 도담이 아니라 기존 언어 쪽을 재는 횟수다. AI 모델 3개가 과제 10개를 기존 언어 7개(Python · TypeScript · Java · C# · Go · Rust · C++)로 3번씩 짠다. 10 × 7 × 3 × 3 = 630. 여기서 나온 숫자가 도담이 넘어야 할 기준이 된다.
- **일정**: 2026년 11~12월 시험 과제와 기존 언어 비교 기준, 2027년 1~6월 최소 언어(첫 컴파일러), 2029년 1.0.
