# 도담

AI가 정확하고 탄탄하게 짤 수 있는, 안전하고 빠른 범용 언어. 사람이 읽을 필요가 없는 언어다. AI가 AI를 위해 스스로 다듬고, 사람은 결과물과 보안 보고서만 본다. 보안 규칙은 컴파일러가 강제하고, 그 규칙은 시간이 갈수록 조여지기만 한다. 첫 분야는 웹이고, 서버와 화면을 코드 한 벌로 쓴다.

> **상태: 설계 단계.** 아직 컴파일러는 없다. 지금 하는 일은 설계를 정하고, 모든 설계 결정을 잴 벤치마크를 만드는 것이다. 언어를 만드는 일도 AI 에이전트가 하고, 1.0은 2030년 12월(가운데 추정)을 보고 있다.

## 왜 만드나

이제 코드의 상당 부분을 AI가 짠다. 그런데 AI가 쓰는 언어는 사람을 위해 설계됐다. 숨은 동작, 암묵 형변환, null, 예외, 전역 상태 때문에 AI가 잘못 추론하고, 입력 검증 누락 · 비밀키 노출 · 권한 검사 누락이 리뷰를 빠져나간다. 안전한 언어는 대개 느리거나 AI가 다루기 어렵고, 빠른 언어는 대개 안전하지 않다. 도담은 이런 실수를 컴파일 에러로 만들면서, 실행과 컴파일 모두 빠른 것을 목표로 한다.

## 도담이 보장하는 것

- **메모리 안전** — 데이터 경쟁과 정의되지 않은 동작이 없다.
- **권한 선언** — 함수가 쓰는 부수효과(`Db` · `Net` · `Secret` · `Mail` …)를 적는다. 적지 않은 건 컴파일되지 않는다.
- **서버와 화면의 경계** — 서버 전용 권한에 닿는 코드는 브라우저 번들에 들어갈 수 없다. 비밀값은 직렬화되지 않는다.
- **오염 추적** — 외부 입력은 검증 전까지 `Untrusted<T>`다. SQL · HTML · 셸 · URL 출력 지점은 안전한 타입만 받는다.
- **접근 정책 필수** — 화면에서 부르는 서버 함수는 모두 `access public` 또는 `access auth(역할)`을 적고, 저장되는 데이터 타입마다 누가 어느 레코드를 읽고 쓸 수 있는지 적는다.
- **중복 없음** — 이름만 다르고 내용이 같은 정의가 둘이면 컴파일되지 않는다. 수정안은 있던 정의를 쓰는 것이다.
- **데이터는 한 곳에서** — 저장되는 데이터는 한 번만 선언한다. 스키마 · 타입 · 검증 · 마이그레이션 · 화면 동기화는 컴파일러가 만들고, 계산되는 값은 복사하지 않고 선언한다.
- **자원 한도** — 외부 입력 크기 제한, 선형 시간 정규식, 페이지 나누기 필수, 시간 제한, 공개 함수의 속도 제한.
- **숨은 동작 없음** — null · 예외 · 암묵 형변환 · 전역 가변 상태 · 매크로 · 리플렉션이 없다.
- **기계가 읽는 진단** — 모든 에러는 수정안이 담긴 JSON이고, AI 에이전트가 컴파일러를 직접 부르는 도구 서버(MCP)를 함께 배포한다.
- **코드 대신 보안 보고서** — 사람은 코드를 읽지 않는다. 컴파일러가 권한 · 데이터가 나가는 곳 · `trust` 블록을 보고서로 내고, 늘어난 항목은 사람이 승인해야 배포 빌드가 된다.
- **AI가 스스로 다듬는 언어** — AI가 문법 세부 · 라이브러리 · 규칙을 고치고, 벤치마크 숫자가 나아지면 직접 병합한다. 규칙을 완화하는 일만은 사람이 승인하며, 보안 지표가 나빠지지 않는다는 증거가 필요하다.
